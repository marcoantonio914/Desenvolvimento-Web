# Exercicio em HTML do Curso Técnico – Desenvolvimento Web
Este projeto em HTML foi criado para praticar o ciclo ** Desenvolvimento Web**.
A página utiliza links,imagens e formatações de caixa de texto para iniciar o desenvolvimento da linguagem html.
## Critérios para validar a atividade.

    - No título (aba) da página: Meus sites favoritos
    - No título do corpo da Página: Meus sites favoritos: Seu Nome
    - No corpo da página, insira:
    - 5 imagens de sites que você gosta;
    - Abaixo de cada imagem, insira o link para o site;
    - Acima de cada imagem, insira o nome do site.
